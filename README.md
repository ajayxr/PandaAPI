# PandaAPI

API REST desenvolvida com **ASP.NET Core** para validação de documentos brasileiros.

## 🚀 Demo

- **Production:** https://api-pandaapi.com.br/swagger/index.html
- **Development:** https://dev-api.pandaapi.com.br/swagger/index.html

## 🛠️ Tecnologias

- C#
- .NET 10
- ASP.NET Core
- Swagger / OpenAPI
- CloudFlare
- Railway

## ✨ Atualmente

- Swagger / OpenAPI

- Ambiente de Development e Production
- Deploy contínuo via Railway
